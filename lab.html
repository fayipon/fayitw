疊出會動的 Banner

不用重新出圖，也不用拆圖層。依照畫面中主體的位置，疊上光束、閃光、粒子和場景特效，再加上鏡頭推移、滑鼠視差和轉場。下面每一層都可以單獨開關，直接比較有沒有差別。

動態層

每一層在做什麼

鏡頭推移 成本 極低

停留期間整個場景緩慢放大 8%，以主體為中心，靜態圖也像有鏡頭在推。特效跟著一起放大，不會錯位。

滑鼠視差 成本 極低

背景往滑鼠反方向、文字往同方向微移，做出前後景深。只在有滑鼠的裝置啟用。

光束光暈 成本 低

主體後方的光暈會呼吸，皇冠上方的光束輕輕擺動。用 screen 混合模式疊在圖上，只會提亮。

場景特效 成本 低

依圖片內容設計：皇冠底座光環、街機螢幕閃爍與掃描線、傳送門漩渦旋轉與能量環。

閃光 成本 極低

在寶石、霓虹星、水晶的位置閃出十字星芒，每顆隨機錯開，不會同時亮。

粒子 成本 中

Canvas 繪製：金粉往上飄、霓虹光斑漂浮、能量粒子被漩渦吸進去。手機自動減量，畫面外會停止。

掃光 成本 極低

一道斜光定期掃過畫面，接著掃過按鈕，把視線帶到行動按鈕上。

文字進場 成本 極低

小標字距收合、標題遮罩上推、重點字流光、按鈕彈出。換張時舊文案先淡出。

五種轉場

視差滑動

外框整片滑動、裡面的圖慢一拍，最自然，適合當預設。

淡入推近

新畫面從放大狀態淡入並推近，節奏柔和，適合質感型品牌。

光圈展開

從新圖的主體中心擴散出來，視線直接落在主角上。

斜切掃過

斜邊快速掃過，速度感強，適合活動、促銷與遊戲。

百葉窗

八條同時打開，有儀式感，適合重大公告或新品揭幕。

一張 banner 怎麼設定

每張 banner 只需要一張主視覺圖，加上這份設定。特效位置用原圖的百分比標示，之後換圖只要重新量一次主體位置。完整設定在 js/slides.js。

// 皇冠：座標都是原圖 960×436 的百分比
{
  image: 'assets/banners/crown.webp',
  label: 'Welcome to your kingdom',
  title: ['Your world.', 'Your rules.'],
  cta: 'Explore games',
  focus: { x: 73.8, y: 33 },                 // 主體中心：光暈、推移中心、光圈起點
  rays: { x: 73.8, y: -8, angles: [-17, -10, -4, 2, 8, 15] },
  ring: { x: 73.6, y: 68.5, w: 44, h: 9 },      // 底座光環
  glints: [[73.8, 11.5], [73.8, 31.5], [64.7, 39.4], ...],
  particles: { mode: 'rise', count: 46, area: [50, 97, 45, 96] },
}
